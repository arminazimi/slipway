## Setting up a custom domain

To set up a custom domain on GitHub Pages:

1. Go to your repository settings.
2. Under "Pages", enter your custom domain in the "Custom domain" field.
3. Save the changes.
4. Create a file named `CNAME` in the root of your repository and put your domain name inside it.
5. Update your DNS settings with your domain provider to point to GitHub Pages.

For detailed instructions, see the [GitHub Pages documentation](https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site).
