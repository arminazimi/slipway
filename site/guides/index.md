These guides go beyond the [configuration reference](../config/). Each one is a task, not an option list.

## Available guides

- [Customize a site](customize/) — set the logo, footer, navigation, search, redirects, and page-agent menu in `mizzen.yml`, and know when a change belongs to the theme instead.
- [Migrate from 0.2](migration/) — move a Jekyll-based Slipway 0.2 site to the engine and theme, keeping URLs and front matter.

New to Slipway? Start with [Install and quickstart](../install/), which creates a site, builds it, and publishes it to GitHub Pages.
