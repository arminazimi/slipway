## Front matter

Every page needs a title and a description.

```yaml
---
title: My page
description: One sentence about the page.
layout: doc
---
```

## Headings

Use `##` for sections and `###` for subsections. The table of contents is built from them.

### Code blocks

A fenced block gets a copy button when scripts are available, and reads fine without them.
