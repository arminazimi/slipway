# Install

Beacon ships as a single binary. Pick the one that matches your machine and put it on your `PATH`.

## With a package manager

- Homebrew: `brew install beacon`
- npm: `npm install -g beacon`
- Go: `go install github.com/example/beacon@latest`

## By hand

Download the archive, unpack it, and check the version:

```bash
beacon --version
```

The binary needs no runtime. Next, go to the [quickstart](quickstart.md).
