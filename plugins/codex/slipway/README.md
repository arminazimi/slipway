# Slipway Plugin for Codex

Codex plugin for working on Slipway documentation sites. It bundles the Agent Skills and the MCP server.

## Scope

Version `0.3.0-dev` is docs-only. The plugin, its Skills, and the MCP server target documentation sites built with the Slipway engine: `slipway.yml`, front matter, directives, and `slipway check`. The blog, portfolio, and marketing layouts of the Jekyll theme are not part of this release.

## Installation

```toml
[plugins.slipway]
path = "/path/to/slipway/plugins/codex/slipway"
```
