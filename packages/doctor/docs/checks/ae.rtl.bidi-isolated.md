# ae.rtl.bidi-isolated

The page title, each `h1`, and each link inside a `nav` element SHOULD isolate a run of one direction when their text holds both right-to-left and left-to-right letters: inside a `bdi` element or an element with a `dir` attribute, or between an isolate mark (U+2066, U+2067, or U+2068) and U+2069.
