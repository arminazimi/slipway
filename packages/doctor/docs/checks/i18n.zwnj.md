# `i18n.zwnj`

Persian joins the prefixes `می` and `نمی` and the suffixes `ها`، `تر`، and `ترین` to the word with a zero-width non-joiner (U+200C): `می‌خواهم`، `کتاب‌ها`، `بزرگ‌تر`. Without the joiner the parts read as separate words, a search for one spelling misses the other, and an agent that copies the text carries the error into titles, links, and translations.

The check reads Markdown prose only. Inline code, fenced code blocks, and front matter are ignored.

## Why it matters for agents
A missing joiner is invisible in review but changes the word: an agent that copies `می خواهم` into a heading, a link, or a translation makes the page harder to find and keeps the mistake for the next agent to copy.

## How to fix
Write the prefix or suffix with a zero-width non-joiner instead of a space, or add the joiner between the stem and the plural suffix. Each finding's `fix` holds the suggested line.

**Bad**
```markdown
می خواهم به خانه بروم.
نمیخواهم دیر برسم.
کتاب ها روی میز است.
```

**Good**
```markdown
می‌خواهم به خانه بروم.
نمی‌خواهم دیر برسم.
کتاب‌ها روی میز است.
```
