# `i18n.spacing`

Punctuation takes no space before it and one space after it, and words are separated by one space. `Hello , world` and `Fine,but` read as typos, and an agent that copies the text carries them into titles, links, and translations.

The check reads Markdown prose only. Inline code, fenced code blocks, URLs, and front matter are ignored. A page in French is not judged on the space before `: ; ! ?`, which French sets on purpose.

## Why it matters for agents
Stray spaces are easy to miss in review and break exact-match search. Each finding's `fix` holds the corrected line.

## How to fix
Remove the space before the mark, add one after it, and collapse double spaces.

**Bad**
```markdown
Hello , world.
Fine,but not here.
Two  spaces here.
```

**Good**
```markdown
Hello, world.
Fine, but not here.
Two spaces here.
```
