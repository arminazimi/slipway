# `i18n.kashida`

Persian and Arabic text sometimes stretches a word with a kashida (`ـ`, U+0640) or by repeating a letter, for example `کـــتاب` or `خیلیییی`. Both are decoration, not spelling: screen readers and search engines read them as extra characters, agents copying the text carry the decoration into other files, and the word no longer matches its dictionary form.

The check reads Markdown prose only. Inline code, fenced code blocks, and front matter are ignored.

## Why it matters for agents
An agent that copies a decorated word into a title, a link, or a translation keeps an invisible difference that breaks search and exact matches. The plain spelling is the source of truth.

## How to fix
Remove the kashida, or collapse the repeated letter to one, and keep the rest of the word as it was. Each finding's `fix` holds the suggested line.

**Bad**
```markdown
این یک کـــتاب است.
خیلیییی خوب است.
```

**Good**
```markdown
این یک کتاب است.
خیلی خوب است.
```
