# Source map, version 0

**Status:** Draft. Version 0 may change without notice until Slipway 1.0. Schema: [`schema/sourcemap.schema.json`](../../schema/sourcemap.schema.json). Background: [ADR 0007](../../docs/adr/0007-source-maps.md).

A source map tells a tool which source file, and which line in it, produced each built page, heading, and link, so a finding on the built HTML can point at the line an agent should edit. Any generator can emit it; Slipway is the reference implementation.

## Location

One file, `/sourcemap.json`, at the root of the built site. It is UTF-8 JSON.

## Fields

### Top level

| Field | Type | Required | Meaning |
| --- | --- | --- | --- |
| `version` | integer, always `0` | required | The format version. A reader rejects a version it does not know. |
| `pages` | array of page | required | One entry per content page. May be empty. |

No other fields are allowed.

### Page

| Field | Type | Required | Meaning |
| --- | --- | --- | --- |
| `url` | string starting with `/` | required | The page's URL path from the site root, as the generator writes it: `/docs/intro.html` or `/docs/intro/`. Each `url` appears once in the file. |
| `source` | string | required | The source file, relative to the site source folder, with forward slashes: `_docs/intro.md`. Never absolute, never containing `..` or a backslash. |
| `sections` | array of section | optional | The page's headings in document order. Absent at level 0. |
| `links` | array of link | optional | The page's links in document order. Absent at level 0. |

### Section

| Field | Type | Required | Meaning |
| --- | --- | --- | --- |
| `id` | non-empty string | required | The heading's `id` in the built HTML. |
| `level` | integer, 1 to 6 | required | The heading level (`h1` to `h6`). |
| `line` | integer, 1 or more | required | The heading's line in the source file. |
| `text` | string | required | The heading's plain text as the built page shows it: no Markdown, smart quotes and entities as characters (`What’s new?`). |

A reader matches a section by `id` first, and by position and `text` when the id differs (ADR 0007, decision 5).

### Link

| Field | Type | Required | Meaning |
| --- | --- | --- | --- |
| `href` | non-empty string | required | The link target as written in the source. |
| `line` | integer, 1 or more | required | The link's line in the source file. |

### Lines

Every `line` is 1-based and counts from the first line of the source file, front matter included, so it is the line an editor shows.

## Levels

What a map contains depends on how it is produced (ADR 0007):

- **Level 0** (classic GitHub Pages, Liquid only): `url` and `source` only.
- **Level 1** (committed map) and **level 2** (Actions plugin): also `sections` and `links`, with exact lines.

## Example

```json
{
  "version": 0,
  "pages": [
    { "url": "/about/", "source": "about.md" },
    {
      "url": "/docs/intro.html",
      "source": "_docs/intro.md",
      "sections": [
        { "id": "install-npm-packages", "level": 1, "line": 6, "text": "Install npm packages" },
        { "id": "faq-whats-new", "level": 2, "line": 23, "text": "What’s new?" }
      ],
      "links": [{ "href": "../missing.md", "line": 8 }]
    }
  ]
}
```

## Validation

The schema checks every rule except "each `url` appears once", which JSON Schema cannot express. `validateSourcemap` in `tools/theme/sourcemap.mjs` checks both.

## Differences from Seaworthy's draft

Seaworthy will read this file after Slipway 1.0 (`seaworthy.sourcemap`). Its contract, `spec/source-map/v0` (Seaworthy task `spec.source-map`, issue #381), was not written on 2026-10-25: Seaworthy's `spec/` folder holds only the report, config, and agent-readability specs. So there is no draft to differ from yet; the table records where this format departs from Seaworthy's existing conventions, to settle when its draft exists. Issues in Seaworthy's repository are opened only if its maintainer agrees.

| Topic | This format | Seaworthy convention | Note |
| --- | --- | --- | --- |
| Version field | `version: 0` | `spec: 0` in the report and config schemas | Named `version` as the task asked. Rename before 1.0 if Seaworthy's draft uses `spec`. |
| File name | `sourcemap.json` | task named `source-map` | Kept as ADR 0007 decided. |
| Paths | relative to the site source folder | report paths are relative to where `verify` runs (Seaworthy ADR 0008) | A reader joins `source` to the source folder it is given. |
