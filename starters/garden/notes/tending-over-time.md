A note is only as good as the last time someone read it with a skeptical eye. Tending is that read: fixing a broken link, replacing an example that aged badly, adding the caveat I meant to add when I wrote it.

Each note records two dates: `planted` when it first appeared, and `tended` when it last changed in a way worth mentioning. The garden index lists the five notes with the latest `tended` date, so the newest thinking is visible without a feed. A note that has not been tended in a year is a signal, not a sin: either it is genuinely [evergreen](stages-of-growth.html), or it should be marked stale.

Tending is cheap on purpose. Changing one sentence and updating the date is a complete edit.
