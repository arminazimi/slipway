# Starter files

Files every new Slipway site copies as they are: everything here except this README.

| File | What it is for |
| --- | --- |
| `AGENTS.md` | What an agent reads before it edits the site: where content lives, the schemas, how to add a page, a post, a menu item, and a translation, how to check an edit, and what never to do. `examples/minimal/AGENTS.md` is a copy; `tools/theme/agents-md.test.mjs` checks that every path and command in it exists. |
| `.vscode/settings.json` | Maps `_config.yml` and `_data/navigation.yml` to their JSON Schemas for autocomplete ([docs/editor.md](../docs/editor.md)). |

Note: If an interactive exercise block is needed, it does not exist yet. Please use plain Markdown for exercises.
