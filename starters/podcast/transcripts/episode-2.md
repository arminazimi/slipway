## Plain text, plain audio

**Ada:** Every page on this site is a Markdown file with a little YAML at the top. The show notes
of this episode are one of them. Open it in any editor and you can read it, change it, or diff
it.

**Ada:** The audio is simpler still. It is a file in a folder, with a name. Nothing points at it
except the episode that plays it and the feed that lists it.

**Ada:** That matters more than it sounds. Most publishing tools make you go through them to
publish an episode. Here, publishing an episode means adding a file and committing it. The feed,
the archive page, the tags page, and the search index all follow from the same file.

**Ada:** The next episode is about writing show notes that people actually finish. Thank you for
listening.
