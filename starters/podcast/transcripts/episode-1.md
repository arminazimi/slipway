## The first episode

**Ada:** Welcome to Slipway Podcast. I am Ada Rahimi, and this is the first episode of a small
show about making things for the web.

**Ada:** Here is the plan. Twice a month, one episode, about twenty minutes. No interviews, no
news, no sponsor. Just one idea, explained slowly, with the pages it is about open in a tab.

**Ada:** Why this format? Because the web is full of things that take too long to say. A page
that loads in a second and reads well is worth more than a feature nobody asked for.

**Ada:** Every episode has three parts. The show notes you are reading now, the audio file, and a
transcript like this one. The transcript is a separate page, so you can read it without playing
anything, and search it.

**Ada:** The feed is a plain RSS file with the iTunes namespace, built by the same site that
builds these pages. There is no other tool in the loop. If you can open a page, you can read the
feed.

**Ada:** That is all for today. Thank you for listening.
