Nimbus keeps a folder of plain-text notes in sync with a remote store. There is no database and no lock-in: if you stop using Nimbus, your files are still Markdown.

This site documents version 2, the current release, and version 1, which is no longer maintained. The sidebar lists both, so a reader on an old release can still find its guide.
