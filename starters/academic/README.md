# Starter files

Files every new Slipway site copies as they are: everything here except this README.

An academic sample for one person: a landing page, publications and talks by year, teaching, and a CV. Everything is plain Markdown, so the site needs no database and no build service beyond GitHub Pages.

| File | What it is for |
| --- | --- |
| `AGENTS.md` | What an agent reads before it edits the site: where content lives, the schemas, how to add a publication, a talk, a course, and how to update the CV. |
| `.vscode/settings.json` | Maps `_config.yml` and `_data/navigation.yml` to their JSON Schemas for autocomplete ([docs/editor.md](../../docs/editor.md)). |
