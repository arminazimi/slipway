## Ask a question

Use GitHub Discussions for questions about using Harbor. An issue is for a bug or a change; a question is not a bug report.

## Include

- The Harbor version, from `npm ls harbor-cache`.
- The Node version, from `node --version`.
- The smallest script that shows the problem.
- What you expected and what happened.

## Security

Do not open a public issue for a security problem. Email the maintainer address in `package.json` and give a week before you publish.
