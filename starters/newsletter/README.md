# Slipway newsletter

This is the newsletter starter site for Slipway. It includes an archive of newsletter issues, a subscribe form, tags, and a feed.

> **Note:** The subscribe form uses plain HTML/Markdown because a dedicated subscribe form block does not exist yet. You can integrate this with the form service of your choice by changing the `action` attribute.

## Local development

1. Run `bundle install`
2. Run `bundle exec jekyll serve`
3. Open `http://localhost:4000` in your browser
