این قالب کوچک‌ترین سایت دو زبانهٔ کامل است: یک صفحهٔ اصلی، همین صفحهٔ درباره و یک [راهنما](/fa/guide.html)، که هر سه به فارسی ترجمه شده‌اند و در نشانی `/fa/` قرار دارند.

زبان‌ها در `_config.yml` تعریف می‌شوند:

```yaml
slipway:
  languages:
    - { code: en, name: English, prefix: "" }
    - { code: fa, name: فارسی, prefix: /fa }
```

هر صفحه `lang` خودش را دارد و `translation_key` را با ترجمه‌اش شریک است. کلید زبان نسخه‌ها را به هم وصل می‌کند و صفحه‌ای که ترجمه ندارد به صفحهٔ اصلی همان زبان می‌رود.

منوها در `_data/navigation.yml` دو فهرست جدا هستند: `main` برای انگلیسی و `main_fa` برای فارسی، تا هر زبان نام صفحه‌های خودش را داشته باشد.
