# Starter files

Files every new Slipway site copies as they are: everything here except this README.

A bilingual sample: English at `/` and Persian at `/fa/`, with every page translated and linked by a shared `translation_key`. The guide explains the setup in both languages ([docs/guides/rtl.md](../../docs/guides/rtl.md) covers the theme side).

| File | What it is for |
| --- | --- |
| `AGENTS.md` | What an agent reads before it edits the site: where content lives, the schemas, how to add a page in both languages, a menu item, and how to check an edit. |
| `.vscode/settings.json` | Maps `_config.yml` and `_data/navigation.yml` to their JSON Schemas for autocomplete ([docs/editor.md](../../docs/editor.md)). |
