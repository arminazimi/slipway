## Goal
A static HTML mockup of the mobile views (drawer navigation, search, on-this-page menu) at 375 px, in light and dark, so the design can be judged before any component is built.

## Files

**Create**
- `docs/design/mockups/mobile.html`

Touch no other file. If one must change, stop and say why in the issue.

## Steps
1. Plain HTML and one inline style block; no build step.
2. Light and dark side by side, or a toggle.
3. Show the drawer open and closed.
4. Follow `docs/design/brief.md`; note any deviation at the top of the file.

## Done when
- [ ] The mockup opens in a browser from the file system.
- [ ] Screenshots in light and dark are attached to the pull request.
- [ ] `npm run check` passes.
