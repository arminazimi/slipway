## Goal
A public WCAG 2.2 AA conformance page generated from the accessibility gate results, published with each release (Lateen differentiator 7).

## Files

**Create**
- `tools/a11y-report/run.mjs`
- `tools/a11y-report/run.test.mjs`
- `site/accessibility.md`

Touch no other file. If one must change, stop and say why in the issue.

## Steps
1. Read the axe and keyboard gate results and list each success criterion with its status and how it is tested.
2. Say plainly which criteria are checked by hand.

## Done when
- [ ] `site/accessibility.md` is generated, and the test fails when it is stale.
- [ ] `npm run check` passes.
