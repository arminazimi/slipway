## Goal
Add Urdu as a built-in language. Urdu reads best in Nastaliq: prefer `Noto Nastaliq Urdu` and `Jameel Noori Nastaleeq` when installed, with a taller line height, and Naskh as the fallback. Use system fonts only (no new font downloads).

## Files
Only these files. Another agent may be working on any other file right now.

**Create**
- `_includes/i18n/ur.html` (every key the English file has)
- `assets/css/lang/ur.css` (font stack, line height, and any script-specific rules)
- `tools/theme/fixtures/lang-ur/` (a doc page and a post page in Urdu)
- `tools/theme/lang-ur.test.mjs`

## Steps
1. Copy the English file's keys; leave a key in English with a `TODO` comment only if you cannot translate it reliably, and say so in the pull request.
2. Build the fixture and assert `lang="ur"`, `dir="rtl"`, and that no English UI string remains.

## Done when
- [ ] Pages with `lang: ur` render right-to-left with Urdu UI strings.
- [ ] `slipway doctor` reports no right-to-left findings on the fixture.
- [ ] `npm run check` passes.

## Working in parallel
- Do not edit `CHANGELOG.md`. If a site owner would notice the change, add `changelog.d/<this issue number>.md` with one line instead.
- Do not edit `package.json`, `package-lock.json`, `.github/workflows/`, `.gitignore`, `ROADMAP.md`, `AGENTS.md`, `_layouts/base.html`, `_includes/head.html`, or `assets/css/slipway.css`. `npm run check` finds new `tools/<name>/run.mjs` and `*.test.mjs` files on its own.
- Write temporary builds to the OS temp folder or under `.tmp/`, never to a new top-level folder.
- Keep schema properties and UI string keys in alphabetical order, and add yours at its sorted place.
- If the task needs a file not listed above, stop and explain why in the pull request instead of editing it.

## Run
```bash
npm ci
npm run check
```
