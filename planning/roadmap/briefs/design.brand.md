## Goal
The logo, favicon, and brand tokens use the new palette so the site, the README banner, and the theme match.

## Files

**Edit**
- `brand/tokens.json`
- `brand/tokens.css`
- `brand/BRAND_GUIDE.md`

Touch no other file. If one must change, stop and say why in the issue.

## Steps
1. Update the brand tokens from the theme tokens; run the existing brand build.
2. Regenerate exports with `npm run build:brand`.

## Done when
- [ ] `npm run check:brand` passes.
- [ ] `npm run check` passes.
