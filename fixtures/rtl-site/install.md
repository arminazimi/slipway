# نصب

بیکن یک فایل اجرایی است. فایل مناسب سیستم خود را دریافت کنید و در `PATH` بگذارید.

## با مدیر بسته

```bash
brew install beacon
npm install -g beacon
```

پس از نصب، نسخه را بررسی کنید:

```bash
beacon --version
```

خروجی باید شبیه `beacon 1.2.3` باشد. اندازهٔ فایل حدود ۱۲ مگابایت (12 MB) است.

سپس به [پیکربندی](configuration.md) بروید.
