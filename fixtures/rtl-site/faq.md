# پرسش‌های متداول

## آیا بیکن به سرور نیاز دارد؟

خیر. بیکن مصنوع را به مقصدی که شما نام می‌برید آپلود می‌کند؛ ببینید [نصب](install.md).

## چرا فهرست نسخه‌ها خالی است؟

دستور `releases` مقصد را می‌خواند، نه حافظهٔ محلی را. همان مقصد باید در [beacon.yml](configuration.md) تنظیم شده باشد.

## کد خروج چیست؟

کد خروج فقط برای خطاها غیرصفر است: `0` موفق، `1` خطای عمومی، `2` پیکربندی نادرست.

```bash
beacon deploy production || echo "exit code: $?"
```

دستورهای بیشتر در [دستورها](commands.md) هستند.
