# Slipway name and logo: use policy

**Status:** Accepted (2026-10-18). Same rules as Seaworthy's, written for Slipway.

The Slipway source code is licensed under the MIT license, which lets you use, change, and share the code. That license does not grant any right to the project's name or logo. This policy says what you may do with them without asking.

## You may, without asking

- **Say that you use or support Slipway.** "Built with Slipway", "Works with Slipway", "A Slipway site". Use the name in plain text.
- **Show the built-with badge** from `brand/assets/badge-built-with.svg`, unmodified, on a site or repository that really is built with Slipway.
- **Write about Slipway**: articles, talks, videos, comparisons, and reviews, including critical ones. Use the name and the unmodified mark to refer to the project.
- **Use the name for a direct integration** when it is clear which part is yours and which is ours: "Acme starter for Slipway" is fine; "Slipway Starter" on its own is not.
- **Fork the code** and run it. A fork must not present itself as the official project (see below).

## You may not, without written permission

- **Name your product, company, domain, package, or account** Slipway, or something confusingly close to it, where it would suggest that it is the official project or endorsed by it.
- **Change the mark**: no recoloring outside the approved variants, stretching, adding effects, or combining it with another logo into a new one. Use the files in `brand/assets/` as they are (see `BRAND_GUIDE.md`).
- **Suggest endorsement**: no "official", "certified by Slipway", or "Slipway approved" unless the project has agreed to it.
- **Sell merchandise** (shirts, stickers, mugs, and the like) with the name or logo, for profit or not. Only the maintainers may. Free stickers for a talk or a meetup are fine if you ask first.

## Forks and redistributions

A fork or a redistributed build that changes the code in a way users would notice must use its own name and logo. Say what it is based on: "based on Slipway". Keeping the license notices is required by the MIT license and is not the same as using the name.

## Asking and reporting

Open an issue labeled `brand` in this repository to ask for permission or to report a misuse. Say what you want to make, where it will appear, and for how long. We answer in the issue so the answer is public.

## Changes

This policy is part of the repository. Changes go through a pull request like any other change. It does not give legal advice, and it does not replace the license. Slipway has no registered trademark yet; if one is registered later, this policy will say so.
