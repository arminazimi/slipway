Create a build

Start a build of a site from a commit. The call returns at once with a build in the queued state.

POST /v1/sites/{site}/builds Needs a token with builds:write
Updated 2 days agoStable since v0.2.0packages/api/src/builds.ts:48

Parameters#

Send the options as a JSON body. The site goes in the path.

NameTypeDefaultDescription
siterequiredstring–The site slug, in the path.
refrequiredstring–The branch, tag, or commit to build.
optionsBuildOptionsinterface BuildOptionsSwitches that change how one build runs. All fields are optional.
Open the full page		{}Switches for this build.
options.cleanbooleanfalseDrop the cache before building.
options.strictbooleantrueFail the build when a check reports an error.
labelstring | nullnullA short note shown in the build list.

Errors#

StatusCodeDescription
201–The build was queued.
401unauthorizedThe token is missing or expired.
422unknown_refThe ref does not exist in the repository.
429rate_limitedToo many builds. Retry after the time in Retry-After.
