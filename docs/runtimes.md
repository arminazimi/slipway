# Supported Runtimes

Slipway supports the following runtimes. End-of-life dates are listed below:

- **Ruby:** 3.3.12 (EOL: ~March 2027)
- **Node:** 24 or later for development (EOL: April 2028); CI still runs 22 (EOL: April 2027), which strips TypeScript types too
- **Jekyll:** 3.10.0 (EOL: N/A)
- **github-pages:** 232 (EOL: N/A)
