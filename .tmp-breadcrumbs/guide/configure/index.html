    Tokens

    Tokens restyle the whole site. Each one maps to a CSS variable.

    slipway:
  tokens:
    radius: 0.75rem

    Languages

    List each language with its URL prefix. The default language has an empty prefix.

    slipway:
  languages:
    - { code: en, name: English, prefix: "" }
