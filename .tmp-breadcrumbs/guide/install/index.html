    Install

    On this page

    • Pick a mode
    • Add the gem
    • Build

    Pick a mode

    The theme works as a gem, through remote_theme, and after “Use this template”.

    Add the gem

    # _config.yml
theme: slipway-theme

    Build

    bundle exec jekyll build

    Open _site/index.html to see the result.
